# SEO Strategy

## In scope
- Public homepage (`/`)
- Public contact page (`/contact`)
- Shared HTML shell and crawler-facing assets (`index.html`, `robots.txt`, sitemap/llms files, manifest, server fallback)
- Social sharing metadata and AI crawler visibility for public routes

## Out of scope
- Personalized child journal routes (`/child/:id`, `/child/:id/summary`, `/child/:id/assessment`)
- Settings utility route (`/settings`)
- Authenticated/admin surfaces (none currently present)

## Target audience
- Parents, practitioners, and early-years educators looking for an EYIT development journal tool.
